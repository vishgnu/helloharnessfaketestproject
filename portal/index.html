Process and playbook

  • Delta code review after every fix round that changes src/ (reviewer, patch file from the orchestrator), or a ledger row "review skipped: <reason>" (L-049, third recurrence).

Feature rounds get a narrow visual pass on the first UI hand-back (L-048, L-053, L-054).
  • Load and perf protocol: at most two heavy agents at once, heavy commands under nice, ledger field loadMax, a perf AC names its scene, a regression is called only on two 5-run sessions at load <= 1.5 or an alternating same-session A/B (L-020, L-041, L-057).
